Privacy

Effective 27 August 2026

Log Scrub Contract is designed so your log data does not need to leave your environment.

CLI and browser demo

The CLI has no telemetry or network code. It reads the policy and fixtures you select, performs redaction and checks locally, and writes only the output or report you request. The browser demo processes its textarea in memory in your browser. We do not receive, store, or inspect those contents.

Local device storage

If you buy or restore the optional Team Pack, the site stores the license token and a time-stamped verification result in your browser's local storage. The checkout token is removed from the address bar immediately and is never written to Cache Storage. This keeps the unlock available between visits and avoids verification more than once per day. Clearing site data removes both. No fixture or policy is stored there.

License verification and purchase

Buying opens the Sociobot billing service, with Dodo as merchant of record. License verification sends the license token to api.sociobot.in; it does not send logs, policies, editor contents, or CLI usage. The merchant processes purchase details under its own checkout privacy terms.

Site delivery

The static hosting provider may process standard request data such as IP address, user agent, requested path, and time to deliver the site and protect it from abuse. This site contains no analytics, advertising trackers, third-party fonts, or third-party runtime scripts.

Contact and changes

Questions can be opened on the project's public issue tracker; do not include secrets or private logs. Material changes will be dated on this page.
